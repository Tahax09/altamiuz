# Owner decisions for release (2026-11-12)

One list of every open decision that only Altamiuz can make. IDs are the canonical ones (CD-n:
spec.md "Content Dependencies" and `docs/content/dependencies.md`; G-n: gaps in
`dependencies.md`; O-n, OD-n: `docs/launch-readiness.md`, `docs/runbooks/deploy.md`). Nothing here
is decided; no ID is renumbered or added. Code `main` at the commit that adds this file.

**Blocks** column: **P** = publication of the affected content (a gate in code or the publishing
checklist) · **B** = the production build (`APP_ENV=production pnpm build` fails) · **D** =
production deployment or launch (the deploy runbook or a launch criterion requires it). "—" = it
blocks nothing technically.

## What actually stops each stage today

- **Production build (B)**, verified 2026-11-12: (1) **CD-13** fails `next.config.ts` immediately;
  (2) the build then loads the CMS configuration while collecting page data, so the build
  environment needs the complete, valid production configuration, and (3) `STORAGE_DRIVER=s3`
  throws because the R2 storage adapter does not exist yet (**O-3**; probe:
  `APP_ENV=test STORAGE_DRIVER=s3 next build` → "STORAGE_DRIVER=s3 is not available yet").
  Required build inputs: approved Arabic segments (CD-13); the storage adapter dependency approved
  and built (O-3); in the build environment real values for `SITE_URL` (https), `DATABASE_URL`
  (TLS), `PAYLOAD_SECRET`, `MFA_ENCRYPTION_KEY`, `HEALTH_READY_TOKEN`, `JOBS_SIGNING_SECRET`,
  `S3_*` (O-3), `SMTP_URL` `smtps://` and `EMAIL_FROM` (O-6), Turnstile keys (O-8),
  `CLIENT_IP_HEADER` or `TRUSTED_PROXY_HOPS` (O-5), `JOBS_TRIGGER=cron`. A synthetic complete set
  passes validation, so nothing else in the configuration blocks the build.
- **CD-12 does not block the build.** It blocks launch (FR-065, SC-012): every legacy URL needs an
  approved redirect. `pnpm seed:redirects` now loads the approved map and refuses to write anything
  while any row is pending.
- **Publication (P)** of each page is held by the content decisions below; the code gates are
  CD-10 (legal pages and the contact form), CD-01/02/05/07 (evidence-gated claims), image alt text
  and SEO fields per language.
