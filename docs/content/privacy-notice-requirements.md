# Privacy notice requirements for the contact form (T128, FR-079, CD-10)

**Status**: input for legal review. This is not privacy-notice text and must not be published as
such. CD-10 (privacy notice, terms of use, cookie statement reviewed for Libyan law and any other
applicable law) is owned by Altamiuz; until it is supplied and approved, the contact form must
not go live (see "Launch blockers" below).

Each row is a fact the notice must cover (FR-079), the current system behaviour it must describe,
and what is still undecided.

| FR-079 item                       | What the system does today                                                                                                                                                                                                                                                                                                                                                                       | Open decision (owner)                                                    |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------ |
| Purpose of collection             | Enquiries are stored in the CMS inbox and forwarded to staff by email so staff can reply (FR-070, FR-074).                                                                                                                                                                                                                                                                                       | Exact purpose wording; legal basis.                                      |
| Data collected                    | Name, email, optional phone, optional organization, subject, message, consent acknowledgement, the page language, submission time, email-delivery status and attempts, scheduled deletion date (FR-070, data-model `enquiries`). No IP address or user agent is stored with the enquiry; the source address is used only, hashed, for rate limiting (5 per 10 minutes) in a short-lived counter. | Whether the hashed rate-limit counter needs disclosure.                  |
| Retention                         | Enquiries are deleted automatically 12 months after submission (`deleteAfter`; daily retention job). Copies may persist in encrypted backups until those backups expire (A-10, FR-077). Audit entries about viewing, exporting and deleting enquiries carry no enquiry content and are kept 24 months (A-9).                                                                                     | Backup retention period once T134 is implemented.                        |
| Who can access enquiries          | Administrators and Owners only (read, export and delete are separate permissions); every view, export and deletion is audit-logged (FR-076). Staff email recipients are configured by Administrators.                                                                                                                                                                                            | Named roles or teams to state.                                           |
| Email delivery processor          | Notifications go through the configured email provider. Proposed for production: Resend (not approved; D-14). Local and test environments use Mailpit / in-memory.                                                                                                                                                                                                                               | Provider choice and its data location (T132).                            |
| Bot-check processor               | The form uses Cloudflare Turnstile in production (`CAPTCHA_DRIVER=turnstile`); the visitor's browser loads Cloudflare's script and the server verifies the result with Cloudflare.                                                                                                                                                                                                               | Disclosure wording; whether Turnstile requires a cookie statement entry. |
| Analytics (if enabled, OD-3)      | Off by default (`ANALYTICS_DRIVER=none`). If enabled (ADR-007): daily totals of page views and accepted enquiries per language, kept 25 months, in the site's own database; no cookies, device storage, identifiers, IP addresses, paths or third-party service. The notice must say so before it is switched on (FR-087).                                                                       |
| How to request access or deletion | No self-service mechanism exists. Administrators can find and delete an enquiry in the inbox (audited).                                                                                                                                                                                                                                                                                          | Contact point and procedure for requests; response time.                 |
| Sensitive information             | The form tells visitors not to include passwords, incident evidence or other sensitive information (FR-078).                                                                                                                                                                                                                                                                                     | Whether the notice repeats this.                                         |

## Launch blockers (US5)

- CD-10: approved privacy notice, published as a page. Since H-3 (2026-11-08) the link next to
  the consent checkbox and the fail-closed gates exist, and a draft notice built only from the
  behaviour above is in the CMS: `privacy-notice.md`.
- CD-11: native-speaker review of the Arabic form strings (`src/modules/i18n/messages/ar.ts`).
- T132: email provider and hosting decisions; production Turnstile keys.
- SC-010 and SC-013: no delivery-guarantee statement may be made until both pass (tasks.md Gate 7).
