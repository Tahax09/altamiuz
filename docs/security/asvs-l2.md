# OWASP ASVS 5.0.0 — Level 2 Verification Register

**Status**: completed for launch readiness (T146, 2026-11-07): every Level 1–2 requirement has a
status and a rationale or evidence. Totals: **96 verified · 73 partial · 11 not
addressed · 73 not applicable** (of 253). `verified` = linked automated test evidence (or, for a
documentation requirement, the cited document); code-review-only items are `partial`. Unless
stated otherwise, evidence comes from the **local production build** — nothing here is verified
on Vercel, Neon or R2 (see `docs/security/adversarial-report.md` A-6). The `not addressed` rows
are listed in `docs/launch-readiness.md` with their owner action. This register is an **engineering target**
(constitution XIV); it is not a certification or a compliance claim.
